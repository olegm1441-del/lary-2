# QA — исправления по пользовательскому плейтесту

Дата локальной проверки: 28 июля 2026.

## Проверенные контракты

- Header CTA «Начать» открывает `/modules`.
- Карточка «Актуальность» с `intent=start` сначала показывает четыре конкурса, затем после выбора ПФКИ открывает форму по URL `/m/social-research?contest=pfki&mode=start&intent=start`.
- Новая форма «Актуальности» содержит отдельные поля результата проекта и ограничений.
- Новая форма «Сценарного плана» разделяет название, идею, место, участников события, целевую аудиторию, расписание, подготовку и ограничения.
- На desktop viewport браузера `1280×720` body font равен 18 px, `scrollWidth === clientWidth`.
- Result navigation отслеживает существование `#result`, включая восстановленный после refresh результат.

## DOCX

- `Актуальность — эталон.docx`: 2 страницы, A4 portrait, кликабельные ссылки, таблицы доказательств и материалов, готовый опрос ВКонтакте, без общего чек-листа.
- `Сценарный план — эталон.docx`: 3 страницы, A4 landscape, таблицы трёх дней, подготовки и логистики, без обрезанных строк и горизонтально сжатых колонок.
- Оба документа zip-valid и читаются через `python-docx`.
- Все отрендеренные страницы просмотрены визуально.
