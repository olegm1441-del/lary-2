# Источники данных

## Общие правила

- Факт или URL попадает в пользовательский результат только из supplied data или после backend/tool verification.
- AI не «вспоминает» точные цифры, нормативные акты, условия конкурса или ссылки.
- Adapter возвращает source, status, retrieval time, URL, period, geography и методику.
- Технические статусы `blocked`, `unavailable`, `parse_error` не показываются пользователю.
- Raw пользовательские тексты, prompts и AI output не пишутся в stdout.

## Зарплата

Production active sources: ГородРабот и Работа России. Выбор делается backend по подтвержденным числам и URL. HH, Росстат и Rabota.ru остаются diagnostic sources до отдельной верификации.

`tab3-zpl-2025.xlsx` содержит отраслевые показатели по РФ без регионального разреза. Он не заменяет показатель по профессии и региону.

`itog_monitor_02-2024.rar` не является подтвержденной базой. Нужны распакованные XLSX/ZIP, заголовки, регионы, отрасли и описание методики.

## Актуальность и исследования

- Минимальная дата публикации: 2024 год.
- Сортировка: новизна, authority, relevance, geography match.
- Для каждого факта: источник, дата, показатель, URL и объяснение релевантности.
- Backend проверяет доступность и соответствие URL до сохранения result snapshot.

## Похожие проекты

Первый источник: `pfki_ALL_WINNERS.xlsx`. Production не читает данные из Downloads. Нужен versioned ingest pipeline, нормализованный snapshot и manifest с датой/хешем. Следующие adapters: ФПГ, Росмолодёжь и другие подтвержденные базы.

## Нормативные акты

Приоритет: официальные правовые порталы и сайты органов власти. Справочные источники требуют явной пометки о ручной проверке актуальной редакции.
